# CollabSpace

A multi-tenant collaborative workspace backend with CRDT-based
document synchronization, real-time editing, RBAC, caching,
background workers, and containerized infrastructure.

## Overview

CollabSpace is a backend-focused collaborative workspace platform
designed around organizations, workspaces, pages, and real-time
collaborative document editing.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- RBAC
- Redis
- BullMQ
- Socket.io
- Yjs
- Hocuspocus
- Docker
- Docker Compose
- Pino
- Swagger / OpenAPI

## Current Status

Core backend functionality is implemented and the project is
currently being polished and documented.
